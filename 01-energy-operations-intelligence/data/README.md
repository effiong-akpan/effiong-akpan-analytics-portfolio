# Data

This folder will contain a synthetic operations dataset and a data dictionary.

Required fields:

- `Date`
- `Asset_ID`
- `Production_Volume`
- `Operating_Hours`
- `Downtime_Hours`
- `Downtime_Category`
- `Maintenance_Event`
- `Estimated_Value_Per_Unit`
- `Data_Quality_Flag`

The final dataset will be explicitly labeled synthetic.
