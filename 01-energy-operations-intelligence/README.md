# Energy Operations Intelligence

This project demonstrates a complete operational-analytics workflow using synthetic data modeled on typical industrial operations.

## Objective

Identify operational patterns and downtime categories that contribute most to estimated production/value loss, then provide evidence-based priorities for management investigation.

## Contents

- `data/` — Synthetic operations dataset and data dictionary
- `analysis/` — Reproducible data-cleaning, KPI, trend, and root-cause analysis
- `dashboard/` — Screenshots or exported views of the dashboard
- `deliverables/` — Executive decision memo

## KPIs

- Uptime percentage
- Downtime hours by category
- Production trends
- Value-loss estimate with clearly stated assumptions
- Weekly/monthly anomaly flags
- Top three investigation priorities

## Tools

Excel; Python with pandas and matplotlib; SQL and Power BI may be added only when used in the project.

## Scope boundary

This project is an analytical demonstration, not engineering design, operations advice, or a representation of any real company or asset.

## Disclaimer

All data is synthetic and created for portfolio demonstration only. Findings do not represent any real company, customer, employer, field asset, Sandia National Laboratories, DOE BOOST participant, or SustainaPower partner.
